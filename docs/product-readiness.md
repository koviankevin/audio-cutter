# 音剪商品化交付

目標：讓陌生使用者能放心處理重要錄音，完成多段刪除、接點確認與下載；音檔持續只在本機處理。商品等級不等同於新增付費、帳號或雲端服務。

## 交付條件與驗收入口

| 項目 | 完成條件 | 驗收入口 |
| --- | --- | --- |
| 工作保存 | 保存樣本區間、待刪清單、復原／重做、輸出與視圖設定；重開後選回原檔即可繼續；專案檔可跨瀏覽器設定檔還原 | `tests/projects.mjs` |
| 原檔核對 | Worker 分塊核對全檔；拒絕同名同大小但內容不同的原檔；可取消且不建立完整原檔緩衝 | `tests/project.test.mjs`、`tests/projects.mjs` |
| 錯誤恢復 | 換檔失敗／取消保留舊工作；儲存被禁止仍能下載專案；匯出容量不足保留待刪清單；交易失敗不留下半份備份 | `tests/projects.mjs`、`tests/export-lifecycle.mjs` |
| 新手操作 | 三步主流程、按需展開進階提示、表單選段與鍵盤操作、清楚標示較早版本的匯出結果 | `tests/product.mjs` |
| 可讀性與鍵盤 | 三種字級、200% 文字縮放、窄螢幕、Canvas 標示、可見焦點與主要流程鍵盤操作 | `tests/font-size.mjs`、`tests/product.mjs` |
| 接點音質 | 可選 5／10 ms 短淡化；預聽與匯出共用處理；預設關閉且不改變樣本總數與聲道 | `tests/join-fades.test.mjs`、`tests/product.mjs` |
| 產品維護資訊 | 版本、更新紀錄、回報與診斷資訊、授權入口；診斷不包含音檔或專案內容；舊快取可重新載入恢復 | `tests/product.mjs` |

## 保存範圍

- 自動備份使用 IndexedDB，只保存剪輯設定、音檔識別與復原紀錄，不保存原始錄音、解碼 PCM 或已匯出的音檔。
- 專案 JSON 版本為 1，上限 8 MiB。還原採全內容分塊 SHA-256 組合識別（chunk-sha256-v1），可以辨識改名但內容相同的原檔。
- 每次開檔或還原建立獨立工作備份，避免多分頁覆寫；還原保留舊備份。列表依時間顯示，可逐批展開並移除。
- 保存完成提示以 IndexedDB 交易完成為準。保存被禁止、配額不足或格式無效時，不顯示成功；可下載專案檔另存。
- 瀏覽器資料可能被使用者或瀏覽器清除。重要工作仍需自行保留原始音檔及下載的專案檔。

## 本輪選測

保存、核對與配額：`node --test tests/project.test.mjs`、`node tests/projects.mjs`。瀏覽器證據輸出至 `test-results/projects-<channel>/`；該資料夾忽略於 Git。

播放／匯出與換檔生命週期受到共用狀態改動影響，沿用既有樣本測試並補跑相關整合案例。新保存功能透過現有 CI 的匯出預聽入口一併驗收，不改變部署的必要關卡。

`tests/product.mjs` 驗證預聽實際緩衝與 WAV PCM 一致、MP3 可播放、匯出期間修改後的版本提示、說明視窗焦點與診斷資料範圍。版面與對比測試是自動檢查，不等同完整 WCAG 認證或實體手機驗收。

## 長音檔證據

2026-10-27，Windows／Chrome 155、Node 24.19、Intel i5-10400，約 28.5 分鐘合成立體聲 MP3（41,060,102 bytes）分段載入約 11.8 秒。刪除三段合計 20 秒、套用 5 ms 接點淡化後，完整 MP3 匯出約 34.2 秒，成品 1,690.88 秒／40,581,120 bytes；匯出期間可預聽，成品尾端播放完成。證據為忽略於 Git 的 `test-results/product-long-chrome/report.json`。

近完成時強制 GC 後，主頁 backing storage 約 0.52 MiB、編碼 Worker 約 0.83 MiB。這不包含全部原生／WASM、磁碟快取或程序記憶體，亦非峰值。合成音檔與單台電腦的結果不保證其他裝置速度；發布版仍需通過同版本必要短檔驗收與正式站核對。
